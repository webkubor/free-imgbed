# 品牌色图标包

- [v2 清单](pack-v2.json)记录每个平台的色值、文件和品牌来源。普通 SVG 取自 [Simple Icons 16.38.1](https://github.com/simple-icons/simple-icons/tree/16.38.1)，彩色单字形在同一路径上应用该版本记录的品牌主色。例如 Discord 使用 [Blurple `#5865F2`](https://discord.com/branding)，GitHub 使用 `#181717`，X 和 Threads 使用 `#000000`。
- [Google 四色 G](https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg)原样取自 Google 托管的 FirebaseUI 素材，色值为 `#4285F4`、`#EA4335`、`#FBBC05`、`#34A853`。具体用法遵循 [Google 品牌指南](https://developers.google.com/identity/branding-guidelines)。
- 抖音继续使用其官网图标 PNG。页面色值取自该 PNG 的实色像素。
- [来源和授权](NOTICE.md)适用于图包原有素材。显示品牌色与提供链接不会改变原标识的权利归属。
