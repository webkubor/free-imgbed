# 社交平台图标包

常用国内和海外平台图标。可按分类浏览，或直接搜索掘金、支付宝等平台名。每张卡片提供品牌色值和直链。有单色版本的图标可切换为单色 SVG。

## 来源与使用

国内平台图标选自 Simple Icons、平台官网、应用商店和标注来源的公开素材。官网图标保留原有颜色，缺少 SVG 时提供 PNG。[查看国内平台来源](https://github.com/webkubor/free-imgbed/blob/main/social-icons/DOMESTIC-SOURCES.md) · [品牌色说明](https://github.com/webkubor/free-imgbed/blob/main/social-icons/BRAND-COLORS.md)
